# 牛马农场 🐮🐴

让工时长成小世界。

看看你的牛马时间能种出多大一片农场。一个 Windows 桌面小软件，把累计使用电脑的时间变成动物、植物和小房子。

## 下载

前往 [最新版本](https://github.com/WWeiyiWang/niuma-farm/releases/latest)，在 Assets 中下载 `NiumaFarm-1.4.0-x64-setup.exe` 并安装。

## 可以做什么

- 记录电脑活跃用时，查看每日统计和每周目标。
- 累计用时获得像素收藏，组成自己的 4×4 小农场。
- 桌面悬浮地块支持拖动、缩放和查看生成进度。
- 记录今日牛马状态：24 种预设表情，也可以自定义名称。
- 查看每日状态变化及每周累计时长，支持暂停、结束和修正记录。

状态计时与工作用时独立。电脑活跃用时可能包含工作和娱乐，并不等于纯工作时间。

## 安装与更新

适用于 Windows x64，需要 Microsoft Edge WebView2 运行环境。

从 1.4.0 起，启动时自动检查新版，也可以在「设置 → 软件更新」检查，点击「下载并更新」安装。安装前会保存记录并创建本机备份，保留用时、收藏、周目标和状态记录。

**1.3.1 用户需先退出软件，手动安装一次 1.4.0。** 此后的新版可在软件内更新。更新包会校验签名；网络、签名或备份失败时不会启动安装。更新时状态记录会暂停，重启后可继续。

## 数据

个人用时、状态和收藏保存在本机。本仓库只提供公开安装包和说明，不包含 MAIN QUEST 的个人计划、日志或数据备份。

关闭主窗口后软件可继续在托盘运行；需要停止时请使用托盘菜单退出。正常退出会暂停状态记录。
